## 请用户批准并执行的 Git 操作

**不要删除** `e:\AgentProject\pi_project\.git`（即使用户后续处理，也应先确认无其他用途）。  
推荐在 `mlpilot` 目录建立**独立仓库**（子目录 `.git` 会优先于上级空 `.git`）：

```powershell
cd e:\AgentProject\pi_project\agent-projects\mlpilot

# 1) 初始化独立仓库
git init

# 2) 建议忽略依赖与产物（若尚无 .gitignore 可先创建）
@"
node_modules/
dist/
outputs/
.issuepilot/
*.tmp
"@ | Set-Content .gitignore -Encoding utf8

# 3) 纳入基线（含 archive/snapshots 与 archive/mlpilot）
git add .
git status

# 4) 基线提交与标签
git commit -m "chore: preserve MLPilot baseline before IssuePilot migration"
git tag mlpilot-baseline

# 5) 迁移工作分支
git checkout -b refactor/issuepilot

# 6) （可选）处理上级空 .git：重命名隔离，勿直接删除
# Rename-Item e:\AgentProject\pi_project\.git .git.empty-placeholder
```

执行完成后请告知，后续阶段将以该仓库的 tag/分支作为回滚点。
